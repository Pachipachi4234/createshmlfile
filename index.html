1. 基本構造・ルール

  • ファイル拡張子：メモ帳やエディタで作成し、文字コード UTF-8 で 〇〇.shml（または .txt）として保存する。
  • コメント行 (#)：行頭に # を書くとコメント（メモ）扱いになり、実行時は無視される。
  • ブロック区切り (_)：異なる言語や処理ブロックを繋ぐときは、単独の行に _（アンダースコア1つ）を書く。
  • スクリプト終了 (__)：ファイルの最後（または処理を止めたい場所）の単独の行に __（アンダースコア2つ）を書くと、それ以降の行は無視される。
  • 行範囲の複数指定 (~)：("1~20") のように 開始行~終了行 で範囲指定ができる（単一行なら ("5")）。

2. [change] ブロック（画面UIの改造・追加・削除）

左パネルのボタンやラベルを書き換えたり、新しいボタンを追加したりする専用ブロック。

  • 文字の置き換え (*)：
    • 書式：(*"元の文字","行範囲")-("新しい文字")（*"元の文字" の * は省略可）
    • 例：("図形追加",*"1~200")-("ルビ図形追加") → 指定範囲内にある「図形追加」の文字を「ルビ図形追加」に書き換える。
  • カスタムボタンの追加 (+ と {button})：
    • 書式：(+"追加する行")-("ボタン表示名","{button}")-{button}:<アクションID>
    • 機能：レイヤー追加エリアの下部に緑色のカスタムボタンを追加し、クリック時に <アクションID> を発火させる。
  • ファイル選択ボタンの追加 (+ と {file})：
    • 書式：(+"追加する行")-("ボタン表示名","{file}")-{file}:<アクションID>
    • 機能：ファイル選択ダイアログを開くボタンを追加し、ファイル選択時に <アクションID> へ選択された File オブジェクトを渡す。
  • 既存ボタンの非表示・消去 (=)：
    • 書式：(="消したい文字")
    • 機能：レイヤー追加グリッドやカスタムエリア内にある該当テキストのボタンを非表示にする。
  • ボタンの並び順移動 (/)：
    • 書式：(/"移動する文字")-("移動先")
    • 機能：レイヤー追加グリッド内の該当ボタンを末尾へ移動させる。

3. [javascript]（または [js]）ブロック（本体機能・キャンバス拡張）

ThumbnailMaker本体の変数や関数に直接アクセスして自由自在に機能を拡張できるブロック。

  • 書き方：[javascript] の次の行に :（コロン）を書き、その下にJSコードを記述する（("1~10"):{ ... } 形式も可）。
  • アクション受信 (onShmlAction)：
    • [change] で定義した <アクションID> と連動させる関数。
    • 書式：onShmlAction('アクションID', (arg) => { ... });（{file} の場合は第1引数 arg に File が入る）。
  • 直接操作できる本体の主要変数・関数：
    • layers：全レイヤーの配列（layers.push(layer) で新規レイヤー追加）。
    • selectLayer(layer)：指定したレイヤーを選択状態にし、右のキャンバスと左の編集パネルを更新する。
    • render()：キャンバス全体を再描画する。
    • createDefaultRubyNodes(shapeType, w, h)：図形・モザイク用の緑●頂点ルビ配列を生成する（'rect', 'circle', 'triangle', 'star'）。
    • bgImage / bgFilter / bgFilterOpacity / bgOpacity / bgColors：背景画像やフィルター設定の直接変更。
