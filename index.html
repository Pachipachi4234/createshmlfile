1. 基本構造・ルール

  • ファイル拡張子：UTF-8 で 〇〇.shml（または .txt）として保存する。
  • コメント行 (#)：行頭に # を書くとコメント扱いになり実行時は無視される。
  • ブロック区切り (_)：異なる言語やブロックを繋ぐときは単独の行に _ を書く。
  • スクリプト終了 (__)：単独の行に __ を書くと、それ以降の行は無視される。
  • 行範囲の複数指定 (~)：("1~20") のように 開始行~終了行 で範囲指定ができる（単一行は ("5")）。

2. [change] ブロック（画面UIの改造・追加・削除）

  • 文字の置き換え (*)：(*"元の文字","行範囲")-("新しい文字") で指定範囲内の文字を書き換える。
  • カスタムボタン追加 (+ / {button})：(+"追加する行")-("表示名","{button}")-{button}:<アクションID> でボタンを追加し、クリック時に <アクションID> を発火する。
  • ファイル選択追加 (+ / {file})：(+"追加する行")-("表示名","{file}")-{file}:<アクションID> でファイル選択ダイアログを開き、選択した File を渡す。
  • 既存ボタンの消去 (=)：(="消したい文字") で該当テキストのボタンを非表示にする。
  • ボタンの移動 (/)：(/"移動する文字")-("移動先") で該当ボタンをグリッド末尾へ移動させる。

3. [javascript]（または [js]）ブロック（本体機能・キャンバス拡張）

  • 書き方：[javascript] の次の行に : を書き、その下にJSコードを記述する（("1~10"):{ ... } 形式も可）。
  • アクション受信 (onShmlAction)：onShmlAction('アクションID', (arg) => { ... }); で [change] のボタンやファイル選択と連動する。
  • 操作できる主要変数・関数：
    • layers：全レイヤーの配列（layers.push(layer) で新規レイヤー追加）。
    • selectLayer(layer)：指定レイヤーを選択状態にし、編集パネルを更新する。
    • render()：キャンバス全体を再描画する。
    • createDefaultRubyNodes(shapeType, w, h)：図形・モザイク用の緑●頂点ルビ配列を生成（'rect', 'circle', 'triangle', 'star'）。
    • bgImage / bgFilter / bgFilterOpacity / bgOpacity / bgColors：背景画像やフィルター設定の変更。

4. [html] ブロック（独自UI・バッジ・パネルの注入）

  • 書き方：("行範囲"):{ と } の間に通常のHTMLタグや {}タグを記述して画面上に埋め込む。
  • 活用例：画面右下の稼働中バッジ表示や、inspectorPanel に追加する専用スライダーUIの作成。

5. ターミナル出力系 3言語ブロック（コンソールログ・対話入力）

  • [python]（または [py]）ブロック：変数代入（x = "文字" / x += "追記"）、ダイアログ入力（x = input("質問文\n")）、出力（print("文字") / print(f"変数:{x}")）に対応。
  • [java] ブロック：変数宣言（String s = "文字"; / int / double / var）と標準出力（System.out.println(s);）に対応。
  • [php] ブロック：変数代入（$v = "文字";）と画面出力（echo $v;）に対応。

6. 重複読み込み時の挙動

  • 同じ .shml ファイルを複数回読み込むと、[change] のボタン追加や [html] の要素注入は上書きされずに重複して増殖する仕様になっている（複数のプラグインを重ね掛けしたり、同じUIを増やしたりできる）。
